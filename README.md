# Realtime Voice Conversation Prototype

A compact React + Vite frontend with a Node.js + Express backend for OpenAI Realtime conversations over WebRTC. OpenAI Realtime handles microphone input, conversation flow, transcript/text extraction, tool-call JSON, and event logging. Final audible AI speech is generated by Hume Octave streaming TTS through the backend WebSocket proxy at `/api/hume/tts-stream`.

The browser never sees `OPENAI_API_KEY`, `HUME_API_KEY`, `HUME_SECRET_KEY`, or Hume voice IDs. It sends only transcript text, the selected voice gender, and optional emotion/style metadata to the backend. The backend resolves the Hume voice ID from `.env`, connects to Hume Octave, and streams audio chunks back to the browser.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Create `backend/.env` and configure:

```bash
OPENAI_API_KEY=sk-your-real-key
PORT=3001
HUME_API_KEY=replace_with_hume_api_key
HUME_SECRET_KEY=replace_with_hume_secret_key
HUME_MALE_VOICE_ID=replace_with_hume_male_voice_id
HUME_FEMALE_VOICE_ID=replace_with_hume_female_voice_id
HUME_TTS_VERSION=2
HUME_TTS_WEBSOCKET_URL=wss://api.hume.ai/v0/tts/stream/input
```

## Run

Start the backend and frontend together:

```bash
npm run dev
```

Open the Vite URL shown in the terminal, usually:

```text
http://localhost:5173
```

## How To Use

1. Type the voice conversation scenario in the textarea.
2. Select Male or Female voice.
3. Click `Start Conversation`.
4. Allow microphone access.
5. Speak naturally. OpenAI Realtime extracts assistant text, sentence chunks are sent to Hume Octave, and the browser plays Hume audio chunks in order.
6. Click `Stop / Reset` to stop mic capture, close WebRTC, close the Hume proxy socket, and reset playback.

## Files

- `src/main.jsx` - React UI, browser WebRTC setup, Realtime event parsing, Hume text streaming, audio chunk playback, and debug inspector.
- `backend/server.js` - Express backend that negotiates OpenAI Realtime sessions and proxies Hume Octave streaming TTS over WebSocket.
- `backend/.env.example` - environment variable template.
- `vite.config.js` - Vite dev server proxy from `/api/session` and `/api/hume` to the backend.

## Notes

- OpenAI Realtime is configured for text output and any Realtime audio track is ignored in the browser.
- Hume Octave is the only active TTS voice output path.
- The debug inspector keeps AI speech text, tool/function call JSON, Hume TTS state, Realtime events, and lip-sync placeholder JSON.
- Lip-sync data is stored as a placeholder structure. No avatar rendering or viseme animation is implemented yet.
- Use a recent Node.js version with built-in `fetch` and `FormData` support. Node.js 20 or newer is recommended.
- Browser microphone access requires `localhost` or HTTPS.
